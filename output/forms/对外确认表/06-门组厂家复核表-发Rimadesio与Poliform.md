# Rimadesio／Poliform 门组项目结论与厂家复核表

> 发送给：Rimadesio、Poliform 供货安装方。
>
> 业主已经确定系统、门扇大小方向和开启方向。项目先用 A-104 画清门位、滑向／开启方向、相邻墙柜、完成面和暂定协调包络，再连同现场复测底图发送。厂家不用重新给方案，也不用问业主加工尺寸；只需判断既定方案“可以／不可以”，然后基于项目图和现场复测返回本项目下单／安装图。

## 一、项目已经确定，不用回复

### Rimadesio Sail（M05 门扇＋M06 顶轨）

- M05 是 Sail 格栅滑门门扇，M06 是同一樘门的 MONOROTAIA 暗藏顶部单轨；两者是一套门，不是两樘门。
- 单轨、单扇、直线滑动；采用官方 DWG 第二种构造：轨道嵌入天花，门垛墙与滑动方向平行。
- 门扇暂按 `1000×2400 mm` 协调，白橡木／浅色木饰面；不要求两道水平横档。
- 顶轨暂按 2000 mm；门向东／图纸右侧完全滑开。
- 地面不做通长下轨，项目不自行添加“地轨导向件”。如果原厂系统在门底需要小型防摆／导向构件，只能由厂家在本项目图上标出准确原厂件。
- 顶轨末端必须可检修；调节滑车或拆换门扇时不拆主吊顶。
- 官方公开资料只把 Sail 定义为日间／夜间室内空间门，没有声明可作淋浴隔断或直接湿区门。本项目仅按卫生间外侧干区入口门复核：门扇不在喷淋范围，地面不积水，暗藏顶轨腔体保持干燥。白橡木／浅色木饰面能否承受卫生间高湿环境及其保修边界，必须由 Rimadesio 书面确认。
- 若厂家只否定木饰面，项目保留 Sail 系统并改用原厂认可的暖色铝合金框＋酸蚀／雾面玻璃；若厂家认为当前门位不够干燥，项目优先把整套门移到防水线外；只有厂家完全否定 Sail 用于该位置时，才改成其他具有卫生间高湿书面质保的顶吊式铝合金＋安全玻璃门。

### Poliform Pivot（M07）

- 墙装单扇 Pivot 轴心门，暂按 `950×2400 mm`，位于 Senzafine 衣柜与墙体之间。
- 使用 Poliform 原厂门框、顶部／地面轴件和金属门扇框，不改普通侧边合页。
- 门关闭时与 Senzafine 衣柜背面的新增护墙板齐平，不与衣柜正面齐平。
- 从走廊进入主卧时向主卧内推；打开后停靠图纸右侧固定墙／次卧一侧。

#### 柜体、Pivot 与墙面的收口结论

Poliform 官方资料已经给出“衣柜与墙之间的 Pivot”通用构造，本项目不采用现场凭经验加封板、发泡或打胶来消化误差：

1. **衣柜侧**：Pivot 门框不得直接固定在 Senzafine 普通侧板上；官方做法是用约 `15 mm` 的专用内侧板替代标准侧板，由该内侧板承接门框。
2. **墙侧**：采用为 Pivot 门框准备的 Poliform 原厂墙框；官方墙框具有约 `35～55 mm` 的伸缩调节范围，用来连接完成墙面与门框。该调节范围不是允许墙体严重不垂直，基层仍须先找方、找直。
3. **衣柜背面／走廊可见面**：优选 Poliform Surface 护墙系统与 Senzafine 背面及 Pivot 连成一套完成面。官方 Surface 通用资料显示护墙板厚约 `30 mm`、墙面挂件占用约 `15 mm`，板间及端部使用原厂铝合金分缝／收口型材；准确组合仍以本项目加工图为准。
4. **若不用 Surface**：可以研究本地定制护墙板，但它只能承担饰面和找齐，不能替代原厂墙框、门框固定基层或轴件。Poliform 必须在剖面图上书面接受其厚度、完成面关系、阴影缝及拆换方式后才可实施。
5. **不接受的现场补救**：不以玻璃胶、腻子、发泡剂或临时窄封板作为主要收口；不让踢脚线穿过地轴和门扇扫掠区；不把原厂调节缝封死到无法调门或拆门。

本项目推荐顺序为：**Senzafine 专用内侧板＋Pivot 原厂门框／墙框＋Surface 护墙板**。如果成本或供货原因改用本地护墙板，则只替换 Surface 饰面层，原厂门框、墙框和固定体系保持不变。

上述尺寸是项目协调值，不是下单尺寸；正式下单尺寸由厂家现场复测后写入项目图。
