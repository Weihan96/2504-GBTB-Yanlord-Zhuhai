# 请 Rimadesio 和 Poliform 确认门组做法

> 业主已经决定门的系统、大小方向和开启方向，不需要厂家重新提供方案选择。请厂家逐行只答“是”或“否”。如果答“否”，请直接在本项目下单／安装图上画出唯一可实施的改法。
>
> M05 是 Rimadesio Sail 滑门门扇，M06 是同一樘门的暗藏顶轨；两者是一套门。M07 是 Poliform Pivot 主卧轴心门。
