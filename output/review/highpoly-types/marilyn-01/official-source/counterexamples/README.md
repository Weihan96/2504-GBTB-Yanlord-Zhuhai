# Counterexample

`Marilyn_Abaco-dwg2SVG-incomplete.svg` is retained only as a negative conversion example. LibreDWG `dwg2SVG` reported that it ignored native `SPLINE` entities, so this file is incomplete and must never be used as official representation geometry. The accepted blue linework is parsed directly from `Marilyn_Abaco.dwg` by `pipeline/scripts/marilyn_01_linework.py`.
