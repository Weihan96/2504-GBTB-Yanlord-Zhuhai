# Baxter Stone / project BST03

项目 IFC 类型 `BST03`、描述 `Stone Bedside Table with Drawer D45` 的单件代表实例为 `1HZoxe$df4cBb4UXXH5J2S`。仓库已确认该实例对应 Baxter Stone 的 45 cm 左抽屉独立床头柜。

- `plan.svg`、`front.svg`、`side.svg`：灰线为实际 IFC `MODEL_VIEW Body` 网格投影；黑线为“基于原始高模几何生成的简化图纸表达”。
- `project-context-furniture-plan.svg`：把同一平面代理按 1:50 原比例放回含墙体和家具的项目平面；项目旧轮廓采用名义 450 mm 包络，完整高模为约 462.48 mm，差异不拉伸。
- `bonsai-camera-*.png`：Bonsai 实际打开单件隔离 IFC、确认 `Body / MODEL_VIEW`、创建四台相机并执行 Blender Render 的结果。
- `official-source/`：归档 Baxter 官方产品页、完整技术表和第 10 页视觉预览。

官方技术表第 10 页有 45 cm 左/右抽屉版本的矢量平、立、侧示意；原生 2D/3D/BIM 下载仍需 Baxter 登录，本项目未取得 CAD。因此技术表只作为品牌、型号、抽屉方向和尺寸证据，不转成蓝色 CAD 线，也不使用第三方 CAD。

项目没有包含这件活动床头柜的可机械对应原生立面投影，所以没有伪造项目上下文立面。独立 Front/Side 候选及 Bonsai 正交渲染仍完整提供。

当前状态为待人眼审核。审批记录保持 `pending` 时，写入器必须拒绝派生 IFC；正式权威 IFC 永远不是允许的输出目标。
