## 3. 可转化的深化方向

以下只作为后续设计评估项，不表示业主已经批准具体产品或节点：

1. **天花与梁体一体化**：包梁节点应同时表达原结构、吊杆或副龙骨、基层板、完成面、转角加强、边缘收口以及与相邻吊顶的标高关系。
2. **风口视觉整合**：木饰面、艺术漆或金属完成面中的风口，可研究同材、同色、齐平或内嵌表达，但不能以“隐形”为由缩小有效开口或遮挡可拆部件。
3. **设备槽整合**：厨房窄条木天花的黑色设备槽可与线性风口语言合并研究，统一灯具、风口、烟感和检修构件的轴线、分段及端部收口。
4. **检修优先**：风口、回风过滤、空调检修和吊顶内阀件必须可下拆或从明确检修口到达；不得依赖破坏主完成面完成维护。

## 4. 进入施工深化前必须关闭

- 风口的送风或回风角色、有效开口面积、风量、风速、压降、噪声和防结露要求；
- 风口尺寸、百叶或散流构件、连接法兰、固定方式、可拆方向和检修净距；
- 包梁和木饰面模块的基层体系、吊挂、结构荷载、防火等级、含水率、六面封闭及伸缩处理；
- 与灯具、烟感、AP、暖风、喷淋或其他天花设备的净距及排版；
- 厨房油烟、温湿度和清洁条件下的材料耐久性；
- 全尺寸或代表性节点样板，经设计、暖通、木作/吊顶施工方和业主共同确认。
