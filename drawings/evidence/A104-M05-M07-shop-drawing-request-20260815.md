已机械确认：项目 IFC 中 M05（门板）与 M06（轨道）是同一精确双成员门组；官方 CAD 证明 Sail MONOROTAIA 为单轨滑动系统，并包含通用一扇/两扇示例。通用示例中的门板、洞口及轨道尺寸不得写成项目订货尺寸。当前 IFC 的 M05/M06 `OverallWidth`、`OverallHeight` 继续留空；可见包围盒只用于现状协调，不作为名义尺寸。

请 Rimadesio／全屋定制一次回复以下项目 shop drawing，图上标注单位和基准：

- 本项目订单号、准确 Sail 系列／型材／玻璃或格栅配置，以及 M05/M06 对应关系；
- 完成面洞口净宽、净高与允许公差；门板名义宽高、数量、搭接量及关闭位置；
- 轨道总长、单轨截面、吊装／侧装方式、轨道中心线和端部收口；
- 左右滑动方向、开启后停位、把手侧、有效净开口和防脱／限位做法；
- 顶部及侧边承重基层、紧固件、允许挠度、调平范围和安装顺序；
- 地面是否无下轨；如有导向件，给出孔位、埋深、防水冲突及可更换方式；
- 门板、轨道、墙／柜完成面之间的净距，检修／拆换路径及验收公差。

该包关闭：`A104-M05-M06-DIMENSIONS`，并影响 A-104、INT1、DET1 和 IDS 中 M05/M06 四个名义尺寸。

## M07｜Poliform Pivot

官方产品资料可确认 Pivot 位于衣柜与墙之间，由独立衣柜与墙装 Pivot 组合；左右开启均为产品能力。开发商 DXF 在 M07 IFC 平面位置附近存在门套实体块，机械坐标吻合，可证明该处既有门套／墙线关系；该块没有可信的大尺度开启弧，不能证明项目 Pivot 左右手、订货宽高或最终门套净距。项目内未找到可定位到 M07 的现场开门照片。

已直接决定的协调规则：Master A 控制面板只能安装在固定、阻燃、有基层且可检修的衣柜见光板／固定墙面，不得落在活动 Pivot 门扇、门套、五金或完整开启包络内。安装面在 shop drawing 关闭前不冻结中心坐标。

请 Poliform／全屋定制提交：

- 项目订单号、Pivot 准确型号／饰面／门扇厚度及五金版本；
- 完成面洞口净宽净高、门扇名义宽高、门套及衣柜侧板完成面净距；
- 从主卧外侧判定的左／右手、开启方向、最大开启角、门扇完整扫掠包络和把手位置；
- 墙装五金、顶／地轴或铰接件的中心、钻孔、埋件、承重基层和调节范围；
- 与 Master A 面板、底盒、线管、柜内层板及检修路径的最小净距；

该包关闭：`A104-M07-EVIDENCE` 和 `E302-MASTER-SIDE`，并影响 A-104、E-302、INT1、DET1 及 IDS 中 M07 两个名义尺寸。
