# 滨海湾施工图纸检查清单

本文用于管理滨海湾装修项目的深化设计、施工图补充、尺寸核对与正式出图。清单以当前 IFC 模型和 `drawings` 目录中的正式 SVG 为基础，并与《滨海湾深化设计注意事项》配合使用。

- 关联文件：[滨海湾深化设计注意事项](./滨海湾深化设计注意事项.md)
- 初始审计日期：2026-08-01
- 当前模型：`2504 GBTB Yanlord Zhuhai.ifc`
- 当前正式图纸：Wall Plan、FFL PLAN、Wall Finish Plan、Sanitary Plan、Furniture Plan

## 使用方法

- `[x]`：已有且已核对。
- `[ ]`：未完成、待补充或待确认。
- 不适用于本项目的项目，应写明“不适用”及原因，不直接删除。
- 每次正式出图前，应依次完成“图纸内容”“尺寸标注”“跨专业协调”和“发布检查”。
- 图纸尺寸必须明确以**结构面、墙体中心线或完成面**中的哪一种为基准；装修定位尺寸原则上优先采用完成面。

## 4. 尺寸与标注统一规则

- [ ] 图纸统一使用毫米；标高单位及零点另行明确。
- [ ] 装修定位尺寸优先标至完成面，结构定位必须明确注明。
- [ ] 同一尺寸不在多张图中重复控制；必须重复时保持一致。
- [ ] 平面尺寸按照总尺寸、分段尺寸、局部定位尺寸分层布置。
- [ ] 门窗、洁具、柜体和设备尽量使用编号关联明细表，避免平面文字拥挤。
- [ ] 安装高度使用 `H=____`、`距完成地面____` 或统一图例表达。
- [ ] 现场决定的尺寸标注“现场复核”及责任方，不留无说明空白。
- [ ] 所有材料、设备和五金编号在图纸与表格中唯一且一致。
- [ ] 详图索引必须能跳转或明确指向对应图号。

## 6. 正式出图前检查

### 内容完整性

- [ ] 图纸目录与实际文件一致。
- [ ] 图号、图名、比例、日期和版本一致。
- [ ] 每个空间均能在平面、天花和必要立面中找到。
- [ ] 所有材料、设备、洁具、门窗和五金均有编号或明确说明。
- [ ] 所有详图索引和引用均有对应图纸。

### 尺寸闭合

- [ ] 主要定位尺寸可闭合，无矛盾或重复控制。
- [ ] 房间净尺寸与墙体、饰面厚度相符。
- [ ] 门洞、柜体、洁具和设备尺寸来自最终选型或明确的预留尺寸。
- [ ] 关键尺寸已与现场实测复核。

### 跨专业协调

- [ ] 平面、立面、天花和节点表达一致。
- [ ] 建筑、家具、给排水、电气、空调和智能设备无空间冲突。
- [ ] 柜门、房门、窗、镜柜和设备检修门可完整开启。
- [ ] 防水、地漏、坡度、门槛和地轨关系合理。
- [ ] 物业、燃气、门窗及设备方限制已经落实。

### 发布与归档

- [ ] SVG 视觉检查通过，文字、线宽和填充可读。
- [ ] PDF 打印检查通过，比例和纸张尺寸正确。
- [ ] 需要交给加工或施工方的 DXF 已检查单位、图层和几何完整性。
- [ ] 文件名和版本号统一，旧版本明确归档。
- [ ] 正式文件与对应 IFC 模型来自同一版本。

## 7. 推荐推进顺序

1. 关闭现状测量、拆除范围和最终墙体布局。
2. 完成 Wall Plan 的墙体、门洞和净尺寸，形成可放线的施工定位图。
3. 完成 FFL、给排水、插座、照明控制和综合天花图。
4. 完成厨房、卫生间、入户家政及固定家具立面和剖面。
5. 完成门窗、五金、防水、材料收口等节点及明细表。
6. 执行尺寸闭合、跨专业协调和正式发布检查。
